# 🐱🐶 Cat vs Dog Classifier

A deep learning web application that classifies images as either Cats or Dogs using Transfer Learning with ResNet18.

(Add your Streamlit link here after deployment)

## 📌 Features

* Upload an image
* Predict Cat or Dog
* Confidence score
* Interactive Streamlit UI
* Transfer Learning with ResNet18

## 🛠 Tech Stack

* Python
* PyTorch
* Torchvision
* Streamlit
* PIL

## 📊 Model Performance

* Model: ResNet18
* Training Accuracy: 98.06%
