# 🐱🐶 Cat vs Dog Classifier

A deep learning web application that classifies images as either Cats or Dogs using Transfer Learning with ResNet18.

## 🚀 Live Demo

https://cat-dog-classifier-vanshgarg.streamlit.app/

## 📌 Features

* Upload an image
* Predict Cat or Dog
* Confidence score
* Interactive Streamlit UI
* Transfer Learning with ResNet18

## 🛠 Tech Stack

* Python
* PyTorch
* Torchvision
* Streamlit
* PIL

## 📊 Model Performance

* Model: ResNet18
* Training Accuracy: 98.06%

## 📂 Project Structure

```text
CatDogApp/
│
├── app.py
├── cats_dogs_resnet18.pth
├── requirements.txt
└── README.md
```

## ▶️ Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
